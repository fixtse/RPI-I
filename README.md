# Redes, Protocolos e Interfaces (RPI-I)

Repositorio de trabajo para el desarrollo y la entrega de las prácticas de la asignatura **Redes, Protocolos e Interfaces**, del **Máster en Internet de las Cosas**.

## Organización

Las prácticas se agrupan en directorios numerados. Cada una puede incluir uno o varios proyectos con su código fuente, configuración e instrucciones específicas.

Actualmente, `Practica 1` contiene proyectos de ejemplo para ESP32 desarrollados con ESP-IDF.

## Proyectos ESP32

Los proyectos ESP-IDF se encuentran en sus respectivos directorios.
